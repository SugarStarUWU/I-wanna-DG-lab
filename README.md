
# I wanna DG-LAB

 
将您的I wanna链接您的DG-LAB！

  

## 开始使用

  1. 点击右侧的Release，下载最新的压缩包
  2. 解压压缩包，打开I wanna DG-LAB.exe
  3. 首先点击上方第二个“郊狼”，点击链接郊狼
  4. 打开DG-LAB 4（没在3试过），点击Socket控制
  5. 点击下方的“创建Socket控制”，扫描新窗口的二维码
  6. 连接完成后，可以修改通道，惩罚模式，波形等，修改完成后记得保存一下uwu
  7. 在I wanna DG-LAB中打开“游戏”，在“游戏窗口”的下拉选择框中，选择I wanna游戏
  8. 可以选择多种触发方式，如果选择“标题死亡数”触发，会在Deaths相关数字更新后触发
  9. 如果选择的游戏不是以Death计数，可以修改下方的“死亡计数关键字”，例如某个I wanna的Death相关是：I wanna XXX Death[1]:0 Time[1]:00:00:01，就需要将“死亡计数关键字”修改为Death[1]
  10. 检查完成后，点击下方的“开始监听/新一局”来开启链接吧！

## 直播强度窗口

点击“游戏”底部的“强度悬浮窗”，打开“I wanna DG-LAB - 实时强度”。

上排是 A: 和 B:，下排是手机 APP 回报的实时强度。未连接或尚未读取到强度时显示“—”。

可拖动、调整大小。主界面最小化不影响它，关闭悬浮窗也不会停止死亡检测或控制设备。

在 OBS 添加“窗口捕获”，选择“I wanna DG-LAB - 实时强度”窗口，按需裁掉标题栏和边框。右键悬浮窗可取消置顶，或改成绿色背景配合 OBS 色度键去背景。不要最小化悬浮窗本身。实际 OBS 捕获效果需在你的直播环境里确认。

## 常用设置是什么意思

 
- 平时强度：临时惩罚到期后恢复的数值。

- 最高强度：程序不能超过这个值，也不能超过手机 APP 的上限。

- 每次死亡增加：每次有效死亡增加的强度。

- 输出时长：一次死亡波形持续多久，单位毫秒；1000 毫秒 = 1 秒。

- 防止重复触发：标题和按键几乎同时触发时，不重复计算同一次死亡。

- 详细连接日志：连接或强度不正常时用于排错，平时不用开启。

  

调整参数后记得点击“保存设置”。
